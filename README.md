Entry for the [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun.

A small Node 22 TypeScript program with no dependencies. Running it writes one short, original rant about an everyday annoyance to `/output/entry.txt`:

```sh
node main.ts
```

The rant is one line of plain UTF-8 text, well within the contest's 400-character cap.
